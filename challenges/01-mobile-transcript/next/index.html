Next Pass Rationale

What This Fixes vs the Original

1. No Component Collisions (Solves Issue #109)

In the original design, when a user enters Edit mode, a floating dark bar appears on top of the audio player and upsell cards. In this next pass, the floating edit bar replaces the audio dock, keeping the viewport clean.

2. Reactive Save State Feedback

Clicking "Save changes" immediately updates the top header badge to ✓ Saved. In the original live product, the badge stayed stuck on "Unsaved edits".

3. 4-Speaker Meeting at 320px

Narrow screens (320px) previously suffered from margin bloat. We use color-coded speaker dots and left-aligned text (no print-style justification) ensuring 100% readable text wrapping.

4. Decoupled Inline Preview Limit

The "Keep reading" banner in the original app permanently consumed 120px of bottom screen real estate. Here, it sits inline right at the 1:05 boundary.

5. First-Class Processing State

Added the missing live transcribing screen with an active pulse indicator, progress bar, and speaker diarization step indicator.
